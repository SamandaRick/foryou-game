# For You 🎂

**For You** is an interactive cake-making browser game built with HTML, CSS and JavaScript.

🎮 **Live demo:** https://foryou-game.netlify.app/

## About the project

The player receives cake orders from customers and builds each cake by matching the requested shape, size, base, cream, icing, layers and decorations.

## Features

- Random customer orders
- Round, square and heart-shaped cakes
- Multiple cake sizes
- Cake bases, creams, icing and decorations
- Level and star progression
- Order streaks and progress tracking
- Free-build mode
- Shop and album screens
- Responsive interface for desktop and mobile
- Progress saved with localStorage
- Animated interactions and special effects
- Cat thief event and other playful game events

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript
- localStorage
- SVG-generated cake graphics
- Netlify deployment
